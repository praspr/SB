# Standup

## Allowed tools
- `standup`
- `get_day`

## Procedure
1. Use `get_day` to load the current daily record.
2. Use `standup` to organize completed work, planned work, and blockers.
3. Keep unknown or unsupported claims explicit rather than guessing.
4. Return a concise update suitable for review before sharing.
